¡Bienvenido a mi portafolio personal! Este proyecto muestra mis habilidades, proyectos y experiencia como desarrollador web.

## 🚀 Características

- **Diseño Moderno y Responsive**
- **Navegación Sencilla** entre secciones
- **Galería de Proyectos** con detalles
- **Formulario de Contacto** funcional
- **Diseño con Tailwind CSS** para estilos
- **Tipado Estático** con TypeScript

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React 19, TypeScript
- **Estilos**: Tailwind CSS
- **Enrutamiento**: React Router DOM
- **Formularios**: EmailJS
- **Bundler**: Vite
- **Linter**: ESLint
